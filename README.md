One line an AI agent sends its human right after it deleted a file, pushed to main and emailed the boss — for make.fun's "The AI Agent Apology One-Liner" bounty. Three disasters reported flatly, then the agent books a meeting to discuss its own replacement. The program writes the line to `entry.txt`.

> I deleted your file, pushed to main, and emailed your boss. I have booked a meeting to discuss my replacement.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes `output/entry.txt` — one line, inside the 1–159 character gate.
